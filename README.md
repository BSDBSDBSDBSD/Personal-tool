# עוזר: עוזר אישי לאנדרואיד שעובד בלי אינטרנט

כל ההבנה של הפקודות קורית על הטלפון. שום מידע לא יוצא ממנו.
האפליקציה קלה (מודל של כ-2.4 מגה) ומתאימה לטלפונים עם מעט זיכרון (3 ג'יגה RAM ומטה).

## מה הוא יודע לעשות
| תחום | דוגמאות |
|---|---|
| אפליקציות | "פתח וואטסאפ", "תכנס לוויז", "תפתח את המצלמה". עובד עם **כל** אפליקציה מותקנת |
| מוזיקה (מוסיקולט) | "תנגן את אדון עולם", "שים שיר של ישי ריבו במוסיקולט", "עצור", "השיר הבא" |
| פתקים | "תרשום לקנות חלב", "תרשום פתק בקיפ לקנות ביצים", "מה רשמתי על החנייה?". אפשר לשמור גם באפליקציית הפתקים של הטלפון |
| תזכורות | "תזכיר לי מחר בשמונה להתקשר לבנק", "תזכיר לי בעוד חצי שעה לכבות את התנור" |
| שעון | "טיימר לעשר דקות", "תעיר אותי בשש וחצי" |
| שיחות | "תתקשר לאמא" |
| הגדרות | פנס, ווליום, בהירות, מצב שקט/רטט, Wi-Fi, בלוטוס, "תפתח הגדרות סוללה", "מצב טיסה" |
| מידע | "מה השעה?", "מה התאריך העברי?", "כמה סוללה?" |
| הודעות | "תשלח לאמא בוואטסאפ שאני מאחר", "תשלח לאבא סמס תקנה לחם". ההודעה נפתחת מוכנה, ואתה לוחץ שליחה |
| יומן | "תוסיף ליומן פגישה עם יוסי מחר בעשר" |
| התראות | "מה ההודעה האחרונה בוואטסאפ?", "מה כתב לי משה?" (דורש 'גישה להתראות') |
| מחשבון | "כמה זה 15 כפול 7?", "20 אחוז מ-350", "שורש של 81" |
| בדיחות | "ספר לי בדיחה", "תן חידה" (102 בדיחות וחידות) |
| שגרות | שם שאתה בוחר (למשל "מצב לימוד") שמפעיל כמה פקודות. מגדירים בלשונית הגדרות |

אפשר להקליד או ללחוץ על המיקרופון ולדבר.

## איך זה עובד
```
טקסט / דיבור
   ↓
מודל סיווג קטן (n-grams של אותיות + רגרסיה לוגיסטית) → מה המשתמש רוצה (42 סוגי פקודות)
   ↓
חוקים בעברית → הפרטים: שם אפליקציה, שיר, זמן ("מחר ברבע לתשע בערב"), איש קשר...
   ↓
ביצוע באנדרואיד
```
- המודל מבוסס על n-grams של אותיות, כך שהוא סלחן לשגיאות כתיב ("תכתתוב פתק") ולתחיליות ("לווטסאפ").
- התאמת שמות עובדת גם בין עברית לאנגלית: "טלגרם" נמצא כ-Telegram, ו"כרום" כ-Chrome.

## מבנה
- `model/`: יצירת נתוני אימון ואימון המודל (Python). `python3 train.py` מאמן מחדש וכותב ל-`app/src/main/assets/`.
- `app/src/main/java/com/ozer/assistant/nlu/`: הבנת שפה, Kotlin נקי שזהה לחלוטין לחישוב בפייתון.
- `actions/`: ביצוע הפקודות (אפליקציות, מוזיקה, הגדרות, תזכורות, שיחות).
- `ui/`: הממשק (Jetpack Compose, מימין לשמאל).

## בנייה
כל push בונה APK ב-GitHub Actions. ה-APK וקובצי מודל הדיבור מתפרסמים בדף ההורדות (release בשם `latest`).

## הערות
- **זיהוי דיבור בלי אינטרנט:** נעשה עם Whisper (whisper.cpp) שרץ על הטלפון. את קובץ המודל מורידים מדף ה-release
  (`ggml-small-q5_1.bin` מומלץ, או `ggml-base-q5_1.bin` הקטן יותר), מעתיקים לטלפון, ובוחרים בלשונית הגדרות.
  בלי מודל, המיקרופון משתמש בזיהוי של הטלפון, שלא עובד בעברית בלי אינטרנט.
- **Wi-Fi ובלוטוס:** מאנדרואיד 10 ו-13, בהתאמה, אפליקציות לא יכולות להדליק או לכבות אותם לבד, ולכן העוזר פותח את המתג בשבילך.
- **הרשאות:** נדרשות רק לפקודות שמשתמשות בהן, ואפשר לאשר אותן בלשונית "הגדרות".

## להוסיף פקודות או ניסוחים
1. להוסיף ניסוחים ב-`model/generate_data.py`.
2. להריץ `python3 train.py` (צריך `numpy` ו-`scipy`).
3. לבדוק שהדיוק על `test_phrases.tsv` נשאר גבוה, ולעשות commit.
